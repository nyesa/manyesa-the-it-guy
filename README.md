# Manyesa The IT Guy — Website

## Free publishing
This website is ready for GitHub Pages.

1. Create a free GitHub account.
2. Create a new public repository, for example `manyesa-the-it-guy`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/root`, then save.
6. GitHub will provide your public `github.io` website address.

## Before publishing
Replace the placeholder phone number and email address in `index.html` with your real business contact details.

## Google visibility
After the site is live, submit its public URL to Google Search Console. Google indexing is free, but appearing in search results is not guaranteed or immediate.
